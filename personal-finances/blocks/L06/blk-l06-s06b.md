# The Village Cattle Fund

## Set the yearly amount

Two hundred dairy farmers keep a common fund. Each farmer pays the same amount every year. When a cow dies, the fund pays that farmer ₹25,000 towards a new one.

Set the yearly amount, then run five years. Some years more cows die than others. You win when the fund pays every claim for five years. The amount must stay below ₹1,000, which is what a farmer can spare in a year.
