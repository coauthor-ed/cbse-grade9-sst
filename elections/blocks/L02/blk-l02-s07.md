# Same Votes, Different Rules

## If One Set of Votes Met Three Rules

Suppose one set of votes, A 40, B 35 and C 25, were counted under each rule.

- Under FPTP, in one constituency, A wins the seat.
- Under the majority system, nobody has more than half, so A and B compete again.
- Under PR, with 100 seats, A gets 40, B 35 and C 25.

**The votes stay the same, and the result changes with the rule.**
