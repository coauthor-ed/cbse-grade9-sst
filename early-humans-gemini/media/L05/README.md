Notes:

- `l05s01_b01.jpg` is the shared six-bowls opener; beats 1-6 each reveal one
  bowl in close-up via `reveal.images`, so `l05s01_b02` through `l05s01_b07`
  must read as the *same* bowl and surface style as the base flat-lay, only
  cropped closer.
- Fig 4.14 itself is a multi-region timeline diagram, not a photograph of
  grain. It is rendered faithfully as the `AgricultureOriginsMapScene` (s02)
  and `GlobalFarmingTimelineScene` (s03) simulations. The six-bowls device
  on s01 is this course's own invented stimulus for introducing the same six
  crops before any date or map is shown - it is not a figure to copy.
- `l05s04_b01.jpg` is reused as the source plate for `l05s06_b01.jpg`: the
  question stimulus recombines the same celt and ring stone against a
  flaked handaxe (Fig 4.9, the form already used for `l01s01_b01.jpg` and
  `l03s01_b01.jpg` elsewhere in this course) so the two objects read as
  consistent with the rest of the lesson.
- The saddle quern (`l05s04_b01.jpg`, `l05s04_b03.jpg`) has no FIGURES.md
  source figure - Fig 4.13 shows an adze, not a quern. It is invented from
  the chapter's own grinding-grain-into-flour passage (pp.80-82) to match
  the `GrainToFlourScene` simulation, which likewise has no source figure.
- All prompts require invented object likenesses and original compositions,
  never any identifiable real specimen, excavation or source photograph.
