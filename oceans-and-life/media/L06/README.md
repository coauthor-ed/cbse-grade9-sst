# Media provenance - L06

Per `docs/copyright-and-sourcing.md`: never extract a textbook's own
photographs; source an openly-licensed equivalent and record its source and
licence here.

**Neither image file below exists yet.** Two blocks carry an `image.src` that
points at a file a later pass has to produce, so the bundle currently has two
dangling image references. Both are listed here with exactly what the file
has to be. Nothing was downloaded and nothing was generated at this stage -
the run had no web access.

## chennai-tsunami-2004.jpg

- Used by: `blocks/L06/blk-l06-s01.json` (`image.src`), on the opening slide.
- Stands in for the source's `Fig. 1.13` (book p.12) - the damage the
  tsunami did on the Chennai coast. **The textbook's own photograph is not to
  be extracted**, and the substitute must be a real photograph of the same
  subject.
- To produce: download a real, openly-licensed photograph of the December
  2004 Indian Ocean tsunami's damage on the Indian coast - a Wikimedia
  Commons file is the likely source, and a news-archive photograph with a
  clear licence is also acceptable.
- The slide's caption must describe **what the file actually shows**. If the
  photograph is of a different place than Chennai (the A&N islands or the
  Tamil Nadu coast, say), the caption and the block's `image.alt` must say
  so, and `image.credit` and `image.license` must be set to match the file
  that was downloaded.
- What the slide needs, from `FIGURES.md`'s `Fig. 1.13` entry:
  1. **Damage in the open, on a coast** - debris, broken structures and
     scattered boats, with the sea or a flooded street in the frame, so the
     reader can see that the wave came in from the sea.
  2. **A sense of scale of the damage**, so the slide's line about the
     coastline taking the beating means something.
  3. No identifiable faces of victims, and no graphic injury.
- Full sourcing brief: `media/L06/chennai-tsunami-2004.source.md`.

## tsunami-detection-buoy.jpg

- Used by: `blocks/L06/blk-l06-s06.json` (`image.src`), on the slide about
  the real hardware.
- Stands in for the source's `Fig. 1.14` (book p.12) - India's tsunami
  detection buoy. **The textbook's own photograph is not to be extracted**,
  and the substitute must be a real photograph of the same kind of buoy.
- To produce: download a real photograph of an Indian tsunami detection buoy
  - the bright yellow float with the frame of instruments above the water and
  the tether running down into the sea. A NOAA DART buoy is **not** the same
  thing and will not do: the slide's point is India's own buoy. Likely
  sources: the Indian Tsunami Early Warning Centre (ITEWC) or INCOIS / NIOT
  publications, or a Wikimedia Commons file whose licence is checked on the
  file page.
- The slide's caption must describe **what the file actually shows**, and
  `image.credit` and `image.license` must be set to match the file that was
  downloaded.
- Full sourcing brief: `media/L06/tsunami-detection-buoy.source.md`.
