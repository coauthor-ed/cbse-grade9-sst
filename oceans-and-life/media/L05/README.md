# Media provenance - L05

Per `docs/copyright-and-sourcing.md`: never extract a textbook's own
illustrations; source an openly-licensed equivalent or generate original
art, and record its source and licence here.

**None of the three image files exists yet.** Three blocks carry an
`image.src` that points at a file a later pass has to produce, so the bundle
currently has three dangling image references. All three are listed here with
exactly what the file has to be. Nothing was downloaded and nothing was
generated at this stage - the run had no web access.

## alappuzha-fishermen.jpg

- Used by: `blocks/L05/blk-l05-s01.json` (`image.src`)
- Stands in for the source's `Fig. 1.10` (book p.10) - fishermen hauling nets
  in the Arabian Sea off Alappuzha, Kerala. The textbook's own photograph is
  **not** to be extracted.
- To produce: download a real, openly-licensed photograph of fishing at
  Alappuzha (a Wikimedia Commons photograph is the likely source).
- Licence: to be recorded below when the file is produced. The block's credit
  and licence fields carry the expected values and **must be corrected to
  match the file that is actually downloaded**.

## gemini-device.jpg

- Used by: `blocks/L05/blk-l05-s04.json` (`image.src`)
- Stands in for the source's `Fig. 1.11` (book p.11) - the
  GEMINI handheld device and the app on a fisherman's phone. The textbook's
  own image is **not** to be extracted.
- To produce: download a real photograph of the device and its app from the
  INCOIS / IMD site (Indian Government works, GODL-India) or from a
  Wikimedia Commons file whose licence is checked on the file page.
- Licence: to be recorded below when the file is produced.

## cyclone-satellite.jpg

- Used by: `blocks/L05/blk-l05-s05.json` (`image.src`)
- Stands in for the source's `Fig. 1.12` (book p.11) - a satellite image of a
  cyclone with a visible eye and spiral rain bands. The textbook's own image
  is **not** to be extracted, and the image must be a **real** satellite
  picture: a generated cyclone is not acceptable.
- To produce: download public-domain imagery from NASA / NOAA, or an ISRO
  image published under GODL-India.
- Licence: to be recorded below when the file is produced.
