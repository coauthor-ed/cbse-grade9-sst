## No image files are needed for this lesson

**This lesson has no image file pending.** Every one of its ten slides
carries a scene instead of a picture, so there is no `image.src` anywhere in
`blocks/L04/` and no dangling image reference. The one source figure this
lesson leans on, `Fig. 1.9` ("Major ocean currents", book p.9), is a **map**,
and a map is drawn by the simulation kit from the real `SimGeo` coastlines -
never lifted out of the textbook page and never redrawn as a static image.

The detail that was read off that map for this lesson, and which a later pass
would otherwise have to open the page for, is now written down in
`FIGURES.md` under "Fig. 1.9": which named currents the map draws red and
which it draws blue, and what the map shows along India's own coastline.
