# Challenge: Build the Column

Seven blocks are loose in a tray: the layers of the Earth, cut into slabs and ready to be dropped into a column that runs from the surface to the centre.

<!-- STEP -->
## Round one: under a continent

Build the column top to bottom. The scale strip on the left has to add up to the full depth of the Earth, so a block in the right place with the wrong thickness is still a wrong column.

**Watch the crust.** Under a continent it is thick. Getting it right is most of this round.

<!-- STEP -->
## Round two: under the ocean

Same column, same depth, same scale strip - and the crust block is now the wrong piece. The ocean floor is thin, and the column it makes is a different column.

<!-- STEP -->
## One block is lying

The tray holds seven blocks for six layers. One of them carries a name that is already on the column, sitting at a depth that name does not belong to. Leaving it in will not be punished visibly - the scale will just never add up.

**Build both columns so the scale reads true. No timer - take as many goes as it takes.**
