# The Last Check

This photograph shows an officer on election duty with the electoral roll open. Voters are waiting with their slips and identity cards, and the officer is checking each name against the roll.

The roll was prepared and revised long before this day. Here, the officer only compares the voter with an entry that already exists.

**Only those whose names appear on the roll are allowed to vote, so a mistake has to be put right before the final roll is published.**
