# Sourcing brief - bhadkeshwar-mahadev-temple-dwarka.jpg

Target file: `media/L02/bhadkeshwar-mahadev-temple-dwarka.jpg`
Referenced by: `blocks/L02/blk-l02-s09.json` -> `image.src`

**Stage 2 had no web access**, so this file could not be sourced. A later pass
with network access has to fetch it, save it under this exact filename, and
fill the licence table in `media/L02/README.md`. The block's `credit` and
`license` fields carry the expected values and **must be corrected to match
the file that is actually downloaded**.

## Hard constraint: a real photograph of the real temple

Never a generated "photograph" of a temple, never an AI image, never a
reconstruction, and never a scan of the chapter PDF. The slide's whole point
is that this is a real place in the sea, so the picture has to be a real
photograph of the Bhadkeshwar Mahadev Temple at Dwarka, Gujarat.

## Where to look

1. **Wikimedia Commons** - search for "Bhadkeshwar Mahadev Temple" or
   "Dwarka temple". Check the **licence on the file page itself**, not on
   the category page. Acceptable: CC0 / public domain / CC BY / CC BY-SA.
   Refused: anything NonCommercial (NC) or NoDerivatives (ND) - the course
   is published under CC BY-SA 4.0 and the validator rejects NC and ND
   licences.
2. **Wikimedia Commons Category:Bhadkeshwar Mahadev Temple** - files here are
   usually photographs of the temple on its rock in the sea.
3. The temple trust's own site, if it publishes a press photograph under a
   licence that allows redistribution. Record the URL.

## What the picture must show

- The **temple on a low rock hillock in the sea**, with water around it.
- Ideally the **stone causeway** leading out to the temple, since the slide
  is about that path being covered and uncovered by the tide. A photograph
  without the causeway is acceptable; a landlocked photograph of the temple
  is not, because it loses the one fact the slide is about.
- Daylight, and a view that makes the sea around the rock obvious.

## What to record when the file is produced

Fill the licence table in `media/L02/README.md`: the file's source page URL,
the photographer's name as given on that page, the exact licence string, and
the date added. Then set the block's `image.credit` and `image.license` to
the same values, and write a caption that describes what the photograph
actually shows.
